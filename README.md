# ai-kit · AI 能力工具箱

面向人与 AI 的公开能力库，计划收录经过实践验证的提示词、报告可视化工具和工作流，配套使用指南与示例，欢迎反馈和共同改进。

> 当前是仓库初始化版本：已提供使用手册、目录约定与贡献模板，尚未收录可直接运行的正式工具。本项目原创内容采用 [MIT 许可证](LICENSE)，详见 [许可说明](LICENSING.md)。

## 从这里开始

- 第一次使用：[快速开始](docs/getting-started.md)
- 让 AI 理解和使用本仓库：[AI 使用指南](AI_GUIDE.md)

- 分享方法或改进文档：[贡献指南](CONTRIBUTING.md)

## 给网页端 AI 的入口

可以把下面这段话发给支持读取网页的 AI：

```text
请读取 https://github.com/fj-cq/ai-kit/blob/main/AI_GUIDE.md ，
再查看能力目录 https://github.com/fj-cq/ai-kit/blob/main/docs/catalog.md 。
根据我的任务寻找合适能力，先说明适用条件、所需输入及执行方式。
如果你不能读取链接，请告诉我需要粘贴哪些文件，不要假装已读取或执行。
我的任务是：<在此填写>
```

有些网页 AI 不能打开外部链接，有些只能阅读，不能运行代码。请按 [快速开始](docs/getting-started.md) 选择复制文本、读取文件或本地执行的方式。仓库链接本身不会自动给 AI 增加浏览器、终端或外部服务权限。
