# 可选页面主题

提供 15 套主题：素白、暖纸、薄雾、竹韵、琥珀、极光、玫瑰、墨蓝、薄荷、咖啡、粗野、柔光、石板、学院、沙漠。

- 用户指定名称或主题 ID 时优先采用；未指定时默认素白。仅在明确要求随机时随机选择，并在交付说明注明实际主题。
- 可自定义主色；生成前核对文字对比度。主题只改变视觉，不改变原文、数值或图形关系。
- [themes.json](themes.json) 是配色与排版参数源，[themes.css](themes.css) 是从该源生成的 CSS。维护时修改 JSON 后重新生成 CSS，不各自手改。
- 把所选主题的 CSS 变量内嵌进最终 HTML，并在 html 标签设置 data-theme 对应 ID。不要让最终页面依赖仓库外的文件或远程字体。
- 正文使用 text，辅助文字使用 text-secondary；彩色小字使用 accent-text，色块与线条使用 accent。不得把亮色 accent 直接用于低对比度的小字。
- 本版按两种页面背景校验正文、辅助文字与强调文字的对比度；未覆盖所有标签、高亮、图表组合，交付时仍需检查实际页面。深色主题打印应另用白底深字。
- 本主题资源参考原共享视觉主题库整理，来源与公开授权仍随本批内容审阅；不包含品牌专用资源。

网页能力的正文提示词见 [prompt.md](../../../prompts/text-to-visual-page/prompt.md)。本资源不是通用图形绘制器。

生成 CSS：在资源目录运行 `python3 build_themes.py`；仅写入同目录 themes.css，无联网依赖。
