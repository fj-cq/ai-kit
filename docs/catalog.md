# 能力目录

当前为初始化版本，尚未收录正式能力。以下目录入口与模板已建立，不表示其中已有可运行的工具。

| 分类 | 正式能力数 | 入口 |
| --- | --- | --- |
| 提示词 | 0 | [prompts](../prompts/README.md) |
| 工具 | 0 | [tools](../tools/README.md) |
| 工作流 | 0 | [workflows](../workflows/README.md) |

新增能力时，在这里增加条目，至少列明名称、解决的问题、状态、执行方式、版本和说明路径。状态统一使用“实验”“已验证”“已弃用”；“已验证”必须注明验证环境与范围，不代表适用于所有 AI。

贡献前可参考 [能力模板](../templates/capability/README.md) 和 [贡献指南](../CONTRIBUTING.md)。
