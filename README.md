# ai-kit · AI 能力工具箱

从你要完成的任务出发，找到可以直接使用的提示词、输入示例和结果检查方法。你可以只用一项能力，也可以按需要组合。

| --- | --- | --- |

| 专业报告读不懂，也不知道结论凭什么成立 | [读懂专业报告](prompts/understand-reports/README.md) | 问题、论证过程、证据与缺口 |

## 怎么开始

五项本地提示词：打开目标能力，复制其中链接的提示词，附上你的材料。“完善任务要求”仅提供外部参考链接，需要到作者页面阅读。不能读取链接的 AI，也可以使用你粘贴的完整文本。只想查看提示词时，明确说“只提取，不执行”。

- [快速开始](docs/getting-started.md)：选能力、准备输入、检查结果。
- [给 AI 的使用指南](AI_GUIDE.md)：按任务选择，不机械执行所有步骤。
- [完整能力目录](docs/catalog.md)：版本、执行方式和状态。

## 当前范围

当前提供 5 项本地提示词、1 条外部参考入口和 1 条组合流程。本地能力流程版本为 `0.2.0-draft`，状态为“实验”；技术架构图默认先生成图片，再代码复刻修复，图片不可用时走纯代码，JSON 合同与绘制器仍为 `0.1.0`。示例用于说明预期行为，不代表所有模型和输入都能达到相同效果。实际检查范围见 [验证说明](docs/validation.md)。当前提供独立的 [Visual 绘图工具](tools/visual/README.md)，不包含提示词管理程序。

提示词可在文本对话中使用；网页制作还需要能够生成文件的环境。仓库链接不会自动赋予联网、终端或外部服务权限。
