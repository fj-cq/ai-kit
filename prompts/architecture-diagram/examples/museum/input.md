# 数字展览平台（虚构测试材料）
目标：展示分发中心与周边系统的接口。读者：集成开发人员。布局建议中心辐射。
S1 八组分别是分发、策展、存储、检索、展厅终端、语音、统计、管理。没有给出系统或部署边界。
S2 分发组含分发中心组件（分派展览资源请求），策展组含策展服务组件（维护展览条目），存储组含媒体库组件（存放媒体），检索组含检索服务组件（按关键词查询），展厅终端组含终端系统（外部系统，播放资源），语音组含语音服务组件（生成解说），统计组含统计服务组件（汇总访问），管理组含管理台组件（调整发布配置）。
S3 分发中心调用策展服务、媒体库、检索服务和语音服务，每次调用分别用于查询条目、读取资源、查找内容和生成解说。
S4 分发中心向终端系统发送展览资源，向统计服务发送访问事件。
S5 管理台调用分发中心更新配置；终端系统向分发中心反馈播放故障。
S6 没有说明服务部署方式，不能假定 Kubernetes 或消息队列。
