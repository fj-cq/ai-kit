# 能力目录

按任务选择，先用一项足够完成工作的能力。当前有 4 项本地提示词、1 条外部参考入口和 1 条工作流；本地提示词与工作流均为 `0.2.0-draft`，状态为“实验”。

| 问题 | 能力 | 执行方式 | 状态 / 版本 |
| --- | --- | --- | --- |
| 报告看不懂，论据和结论连不上 | [读懂专业报告](../prompts/understand-reports/README.md) | 文本分析；必要时读取附件 | 实验 / 0.2.0-draft |
| 内容已明确，但表达难读 | [把文字写清楚](../prompts/write-clearly/README.md) | 文本改写 | 实验 / 0.2.0-draft |
| 概念不懂、不会应用 | [把专业内容讲明白](../prompts/explain-concepts/README.md) | 分层讲解与检验 | 实验 / 0.2.0-draft |
| 任务要求不够具体 | [完善任务要求](../prompts/refine-tasks/README.md) | 到作者页面阅读；本仓库不附正文 | 外部参考 / 不提供本地版本 |
| 定稿需要图文呈现 | [文字稿转图文网页](../prompts/text-to-visual-page/README.md) | 文件生成；按环境检查显示 | 实验 / 0.2.0-draft |
| 需要理解后整理并交付内容 | [专业材料到易读内容](../workflows/material-to-readable-content/README.md) | 按需组合上述能力 | 实验 / 0.2.0-draft |

“实验”意味着有可用的使用说明和示例，仍需要更广泛的实际使用验证。详细证据见 [验证说明](validation.md)。[来源说明](content-sources.md) 记录本批内容的授权核实状态。

[工具目录](../tools/README.md) 提供 Visual 绘图工具（实验 / 0.2.0-draft）。模板仅用于贡献，不计入能力数。
