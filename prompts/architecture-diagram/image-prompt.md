# 中等详细度图片提示词

按已核对的模块与关系填充下面模板，作为当前环境图片生成功能的输入。默认只生成一张，不默认进行多档或多轮试验。中等详细度指内容层次，不设固定字数或固定模块数量。

```text
请生成一张中文技术逻辑架构图，标题“[系统名称｜技术逻辑架构]”，用于[目标读者与沟通目的]。如附有参考图，参考其风格与构图，内容以以下模块和关系为准。
采用宽屏横版、浅色背景、深蓝标题、圆角卡片和清晰箭头；按职责分区，用柔和配色区分模块，文字简洁可读。
主要区域与模块：[逐组列出模块名称与一句职责，保留必要层级]。
主要关系：[起点→终点、调用目的或传递内容；标清方向、并列、反馈和条件]。不把并列改为串行，不增加清单之外的连线。
必须保留的边界：[权限分区、职责、系统内外、恢复规则等影响理解的限制]。关键原文：[必须准确呈现的短句]。
底部简要说明[关键状态或恢复原则]。布局按内容调整；若超出单图容量，按已定视图拆分，不删除关键模块和关系。不增加无依据的系统，不把设计方案写成已上线结果。
```

有参考图时一并提供；没有时按本次模型生成。模板中的占位项不得原样出现在成品。生成后按原材料核对图片，再由代码复刻和修复局部；图片不能替代关系模型。
