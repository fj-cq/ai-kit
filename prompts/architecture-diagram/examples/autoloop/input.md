# Autoloop 任务闭环（虚构测试材料）
目标：展示自动任务平台的控制与结果反馈。读者：平台开发人员。
S1 系统有三组：任务接入、执行、质量反馈。三组都在“自动任务平台”系统边界内。
S2 任务接入组包含任务 API（接收任务请求）和计划器（拆解并调度任务）。执行组包含工作器（执行步骤）和工具适配器（调用受控工具）。质量反馈组包含检查器（核对执行结果）和结果库（存储检查记录）。上述六项都是组件。
S3 任务 API 调用计划器；计划器调用工作器；工作器调用工具适配器。
S4 工具适配器向工作器返回执行数据；工作器把执行结果传给检查器；检查器把检查记录传给结果库。
S5 检查器向计划器反馈失败原因；结果库向任务 API 提供已完成任务结果。
S6 不涉及真实产品或公司的实现；未说明用户认证机制，不要补画认证服务。
