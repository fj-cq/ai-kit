# 文字稿转图文网页

文字稿已确定，需要通过图形和排版帮助连续阅读。

**准备：** 完整文字稿，包括标题、表格和限定条件；可选提供配色或风格参考。

**得到：** 保留输入原文的单文件 HTML，配上解释必要关系的图形。

## 开始使用

复制 [完整提示词](prompt.md)，附上本次材料。能够读取本地文件的 AI 可以直接读取本文件与 prompt.md。只想获取正文时说“只提取，不执行”。

先看 [示例输入](examples/input.md) 与 [参考输出](examples/output.html)。示例使用虚构材料，用来比较结果形态，不是实际业务成果。

## 使用条件

- 环境：生成文件的环境；浏览器可用于显示检查。无需安装视觉库或依赖品牌资源。
- 不适用于：自动改稿、补造缺失数据，或只能对话却要求声称已生成可下载文件。
- 副作用与成本：提示词本身不调用服务；AI 使用可能产生所在产品的费用。网页制作会写出文件；其余能力默认返回文本。联网、外发或发布需另有授权。

## 如何判断完成

按提示词末尾的检查项对照你的原始输入，不能只看输出是否流畅。示例沿用首版演示，尚未按恢复后的完整提示词重新独立运行；实际输出格式以 prompt.md 为准。
