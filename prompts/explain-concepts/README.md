# 把专业内容讲明白

读者不熟悉概念，需要理解机制、边界并迁移到新场景。

**准备：** 一个概念或一段专业材料；可选说明读者已知什么、想用来做什么。

**得到：** 一句话版、机制版、细节与边界，以及判断、迁移、反例三道检验题。

## 开始使用

复制 [完整提示词](prompt.md)，附上本次材料。能够读取本地文件的 AI 可以直接读取本文件与 prompt.md。只想获取正文时说“只提取，不执行”。

先看 [示例输入](examples/input.md) 与 [参考输出](examples/output.md)。示例使用虚构材料，用来比较结果形态，不是实际业务成果。

## 使用条件

- 环境：仅需文本对话；涉及当前或高风险事实时需另外核实来源。
- 不适用于：要求逐字保留原稿的排版任务，或需要以教学例子替代真实证据的任务。
- 副作用与成本：提示词本身不调用服务；AI 使用可能产生所在产品的费用。网页制作会写出文件；其余能力默认返回文本。联网、外发或发布需另有授权。

## 如何判断完成

按提示词末尾的检查项对照你的原始输入，不能只看输出是否流畅。示例沿用首版演示，尚未按恢复后的完整提示词重新独立运行；实际输出格式以 prompt.md 为准。
