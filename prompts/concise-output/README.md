# 按读者和篇幅组织输出

让读者在有限篇幅里抓住结论、理解依据、知道下一步。适合从零写中文内容，也适合压缩已有文本；与“把文字写清楚”相比，本提示词更强调篇幅预算、阅读顺序和长文分步确认。

## 开始使用

复制 [完整提示词](prompt.md)，附上任务或已脱敏材料。可提供四个参数：读者、篇幅区间、用途、必须保留的内容。未提供时按提示词第 12 节默认执行；只想获取正文时说“只提取，不执行”。

虚构输入示例：

```text
读者：第一次使用公共图书馆预约系统的读者。
篇幅：150–200 字。
用途：转发同事。
必须保留：预约成功后仍需在开放时间内到馆取书。
材料：预约成功不代表图书已送到家。读者需等候取书通知，在通知指定期限和开放时间内到馆取书。
任务：把材料写成简短提醒，不新增服务承诺。
```

期望检查点：第一句给结论；保留到馆取书、通知期限和开放时间；不新增送书服务或真实机构信息。此例只说明输入和验收方式，不是独立模型运行记录。

## 使用条件与限制

仅需文本对话。提示词本身不调用外部服务、不写入文件；所在 AI 产品可能收费，联网或发布需另有授权。

提示词原文保留。正文含若干需要结合任务判断的约束：第 12 节未替缺失的读者、用途和必须保留项给出具体取值；1501–2500 字的节数与每节最低字数可能难以同时满足；550–650 字区间跨越第 2 节的结构分界。使用时说明采用的解释，不补造用户要求，也不把规则冲突伪装成全部达标。

字数、句长和术语数量需要实际核对；模型自检不能保证准确。压缩材料时仍须核对判断强度、事实与条件，不能用删去必要条件来满足字数。
