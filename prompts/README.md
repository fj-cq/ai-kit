# 按任务选提示词

| 任务 | 能力 | 注意区别 |
| --- | --- | --- |
| 技术材料转系统架构图 | [技术架构图生成](architecture-diagram/README.md) | 默认图片先行，再代码复刻修复；图片不可用时纯代码 |
| 理清专业报告的内容和论证 | [读懂专业报告](understand-reports/README.md) | 先理解证据，需要时再改进讲述 |
| 把确定的意思写清楚 | [把文字写清楚](write-clearly/README.md) | 不新增教学例子或改变事实 |
| 按读者和篇幅控制输出 | [按读者和篇幅组织输出](concise-output/README.md) | 保留原文；含默认篇幅、压缩和长文分步规则 |
| 学会一个专业概念 | [把专业内容讲明白](explain-concepts/README.md) | 可以加入标识清楚的教学例子 |
| 补齐任务中的关键要求 | [完善任务要求](refine-tasks/README.md) | 外部参考；到作者页面阅读，仓库不附正文 |
| 把定稿变成图文页面 | [文字稿转图文网页](text-to-visual-page/README.md) | 逐字保留输入稿，只改变呈现 |

新增“按读者和篇幅组织输出”提供完整原文、虚构输入和验收要点，尚无独立模型运行输出。其余五项本地提示词各有可复制正文、虚构输入和参考输出；架构图案例附 JSON 模型与核对记录；“完善任务要求”仅为外部参考入口。版本与检查范围见 [能力目录](../docs/catalog.md)。需要多步处理时使用 [组合流程](../workflows/material-to-readable-content/README.md)。
